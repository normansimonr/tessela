# Legacy Qere/Ketiv scripts

These are the original Tessela scripts that produced the earlier, simpler
Qere/Ketiv datasets (verse list with a `k`/`K` type only). They have been
superseded by the richer dataset in the parent directory
(readings, transliteration, gloss, root, Strong's, morphology, variant type,
proper-name flag).

**Do not run these scripts against the parent directory**: they would overwrite
the richer CSVs with the older, poorer data. They are kept only for historical
reference.
